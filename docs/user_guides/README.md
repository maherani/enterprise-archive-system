## خط‌مشی اسناد زنده (Living Document Policy)
کلیه راهنماهای این پوشه **اسناد زنده و پویا** هستند. با اعمال هرگونه تغییر ساختاری، ارتقای نسخه سامانه یا تغییر در صفحات کاربری، مستندات و تصاویر موجود در این پوشه به‌صورت همگام با کد منبع به‌روزرسانی می‌شوند.
